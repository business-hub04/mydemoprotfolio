Mbali Mahlangu Portfolio - Mbalz Creations Case Study
Project Overview
This project is a professional portfolio and a detailed "Case Study" page for my business, Mbalz Creations. It is designed to show my skills as a Software Developer and Web Designer to potential clients and employers.

Features
Clean Design: A minimalist black and white theme that looks professional and modern.

Interactive Slideshow: A 4-image slideshow that shows different parts of the Mbalz Creations website.

Project Details: A breakdown of my role, the technology I used, and the goal of the project.

Contact Form: A working form where people can send me messages directly. It asks for their Name, Email, WhatsApp number, and Message.

Mobile Friendly: The website works perfectly on phones, tablets, and computers.

Technologies Used
HTML5: To build the structure of the website.

CSS3: To design the layout, colors, and animations (like the shimmer effect and slideshow).

JavaScript: To make the slideshow work and to handle the contact form.

Formspree: A service used to send form messages straight to my email.

Google Fonts: Used the "Inter" font for a clean look.
